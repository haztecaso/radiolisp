# Backend (proxy http y lo que suena) Implementation Plan

> **For agentic workers:** executed inline by one agent (user asked: no subagents).
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Clojure backend that proxies `http://` streams for https pages and pushes ICY
titles over a WebSocket, plus the frontend changes that use both.

**Architecture:** One JVM process (Ring + Jetty 12 on virtual threads) serves the frontend
build, `GET /api/stream/<uuid>`, `GET /api/ws` and `GET /api/health`. A relay keeps one
upstream connection per station uuid and fans audio out to proxy listeners and titles out
to WebSocket subscribers. Spec: `docs/specs/2026-10-20-backend-design.md`.

**Tech Stack:** Clojure 1.12, JDK 21 (`java.net.http`, virtual threads), ring-core and
ring-jetty-adapter 1.15.6, core.async, data.json, cognitect test-runner; ClojureScript
frontend unchanged in stack.
