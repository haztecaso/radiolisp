### Task 2: artwork model in `views/art.cljs`

**Files:** `frontend/src/radiolisp/frontend/views/art.cljs`, `frontend/test/radiolisp/frontend/views/art_test.cljs`

- [ ] Tests:
  - `fit`: `:small` when the longer side < 96, `:cover` when squarish (0.8–1.25),
    else `:contain`; no size → `:contain`.
  - `guess-by-url`: `.jpg`/`.jpeg` (any case, with a query) → `{:alpha? false}`;
    png/svg/ico/unknown → `{:alpha? true}`.
  - `probe-result` on a flat RGBA vector of side n: transparent border → `:alpha? true`;
    an opaque white border → `:edge "#ffffff"`; dark opaque pixels → `:dark? true`;
    a mixed opaque border → `:edge nil`.
  - `mode`: `:text` with no favicon or a broken image; `:display` wins; otherwise
    the probe (when its `:src` matches the favicon) or the URL guess decides
    (`:pad` if alpha, else `:image`).
  - `view` keeps the old contract for names/initials.
- [ ] Implement. `view` takes the whole state (`:art` fits `{:fit :w :h}` or
  `:broken`, `:probes` id → `{:src :alpha? :dark? :edge}`), sets classes
  `[class tN fit mode plate? lit?]`, an inline edge background in `:image` +
  not-cover, and `width: 2w px` on small images. `:art/sized` carries the src.
- [ ] `bb test` green.
